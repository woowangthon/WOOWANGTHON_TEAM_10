# mijuk00 — 팀 기억 기반 공동 AI 조언자

팀원이 짧게 남긴 미완성 생각을 작성자 확인 후 팀 기억에 저장하고, 다른 팀원이 작업할 때 관련 생각을 찾아 근거 있는 조언으로 연결하는 웹 서비스.

- 설계: [`docs/구현_구체화.md`](docs/구현_구체화.md)
- 보안 점검: [`docs/보안_점검.md`](docs/보안_점검.md)

## 현재 구현된 것

**1단계: 저장·권한 골격**
- 이메일·비밀번호 가입/로그인 (scrypt 해시, 서명된 세션 쿠키, 로그인 시도 제한)
- 팀 만들기, 초대 코드로 가입, 탈퇴
- 메모: 초안 저장 → 작성자 확인(정확한 버전·해시 고정) → 팀 공유 → 수정/철회/삭제
- 작업 만들기·수정

**2단계: AI 연결 지점 뼈대 (AI 없이 동작)**
- 메모 정리(재진술) 흐름: 원문과 정리문 비교 → 의도 맞음 / 직접 고침 / 원문 그대로
- 작업 조언 파이프라인: 권한 → 후보 검색 → (AI) 관련성 판정 → (AI) 조언 생성 → 서버 검증 → 확정 직전 재확인
- 조언 구획: 팀 메모에 있는 내용 / 연결 이유(AI 해석) / AI 확장 / 반론·확인 / 근거 없는 일반 제안
- 적용·보류·제외 기록, 같은 제안 반복 시 접어서 표시
- 근거 메모가 철회·수정되면 조언 무효화·숨김, 삭제되면 저장된 조언 본문까지 지움

### AI 연결 상태 (`AI_PROVIDER`)

| 값 | 동작 |
| --- | --- |
| `none` (기본) | AI를 부르지 않음. 메모는 원문 그대로 등록, 조언은 **키워드가 겹치는 팀 메모만** 표시 (연결 이유·제안은 만들지 않음) |
| `fake` | 개발용 가짜 응답. 모든 출력에 【개발용 가짜 응답】 표시. **운영 환경(`NODE_ENV=production`, Vercel)에서는 거부됨** |
| `claude` | 다음 단계에서 추가 (API 키 필요) |

모델 출력은 `src/lib/ai/validate-output.ts`에서 검증한다. 건네지 않은 근거 번호, 원문에 없는 인용, 구획 규칙 위반은 버린다.

## 로컬 실행

필요: Node.js 20.9+, PostgreSQL 14+ (pg_trgm 확장)

```bash
npm ci
```

```bash
cp .env.example .env.local   # 값 채우기. .env.local 은 커밋되지 않음
```

```bash
DATABASE_URL=postgres://... npm run db:migrate
```

```bash
npm run dev
```

## 테스트

```bash
DATABASE_URL=postgres://.../테스트용DB npm test
```

테스트는 지정한 DB의 테이블을 비우므로 **반드시 테스트 전용 DB**를 쓴다.
