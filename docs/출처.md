## 4. AI

| 대상 | 무엇을 | 어디에 |
| --- | --- | --- |
| **OpenAI `gpt-6.1-terra`** (Responses API, 추론 강도 `none`, `store: false`) | 서비스 기능: 메모 정리, 관련성 판정, 조언 작성 | `src/lib/ai/openai.ts`, `src/lib/ai/prompts.ts` |
| **Claude Code** (Anthropic AI 코딩 에이전트) | 개발 도구: 코드·테스트·문서·평가 실행기 작성 | 해당 커밋에 `Co-Authored-By: Claude` 표시 |

AI 출력은 서버가 근거 번호·인용·구획 규칙을 다시 검사한 뒤에만 사용자에게 보인다 (`src/lib/ai/validate-output.ts`).

## 6. 글꼴·이미지·아이콘

외부 글꼴·이미지·아이콘을 쓰지 않는다. 화면 글꼴은 사용자 기기의 시스템 글꼴(`system-ui`, Apple SD Gothic Neo, Noto Sans KR 등)을 쓴다. UI 디자인을 다른 AI 도구로 바꾸면 이 절과 §4 에 그 도구를 추가한다.
